# Painel Portal de Algodões 2027

Painel público dos sócios: https://tikalpraia.github.io/painel/

- Atualiza sozinho às 8h58 e 16h58 (horário da Bahia) pela ação "Atualizar painel" (aba Actions).
- O painel pede senha. Todos os dados ficam criptografados (`data/*.enc.json`) e só abrem com ela.
- Segredos do repositório: `SHOTGUN_TOKEN`, `RECORRENCIA_SALT` e `PAINEL_SENHA`.
